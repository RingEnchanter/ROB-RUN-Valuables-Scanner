# ROB RUN Valuables Scanner

Download: soon

Scanner for safes, rare drops and key items, with tiers under control.

| Tier | Contents | Default |
| --- | --- | --- |
| violet | safes, rare loot, keys | on |
| amber | armor, medkits | on |
| grey | generic containers | off |

## Filters

Minimum tier, range 80-550 m, hide emptied, hide locked.

## Use

Start with violet only. Drop to amber inside compounds, back to violet on rotation. Grey stays off, it only adds noise.

## Install

1. Extract, admin loader, game
2. INSERT, set the tier floor
3. F3 toggles

## Troubleshooting

Stale markers: loader restart, session handle lost. Overload: tier floor up. Empty screen: category boxes off.

Item table is version bound, patches need a new build. Windows 10/11, Steam, EAC.
